CODE REPOSITORY
===============

Primary analysis notebook (canonical pipeline): ThesisV10.ipynb (included in this folder)

The notebook reproduces the entire study end to end:
  1. Loads the 746-assembly Fusion 360 dataset (see ../Datasets/fusion360_independent_labels.csv)
  2. Builds the technical, semantic, and structural cosine-similarity matrices
  3. Performs 5-fold cross-validated hybrid weight selection (Pitfall B3 fix)
  4. Evaluates all seven methods with bootstrap CIs and Wilcoxon tests
  5. Constructs the OWL ontology (4,476 RDF triples) and SPARQL queries
  6. Generates every figure (PDF) and result table (CSV) used in the paper

All outputs are written to: ontology/outputs/figures/ and ontology/outputs/tables/
